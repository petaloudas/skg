SKG Port Agency website files

To place this website on your domain:
1. Extract this ZIP archive.
2. Upload index.html and the complete images folder to your domain's website root
   (often named public_html, www, or htdocs).
3. Keep the images folder beside index.html so both vessel photos load.

The contact form opens the visitor's email application and prepares a message to
agency@skgport.com. The email address itself must be set up with your email or
domain provider before it can receive messages.
